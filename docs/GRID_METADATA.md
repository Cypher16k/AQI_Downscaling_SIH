\# Hyderabad ORR 1 km Master Grid



\## Study Area



Hyderabad ORR enclosed study region, Telangana, India.



\## Boundary Source



Telangana State Remote Sensing Applications Centre (TGRAC)



Dataset:

Outer Ring Road - 1448 Sq. Km



\## Grid



Spatial resolution:

1 km × 1 km



Number of grid cells:

1543



Grid CRS:

EPSG:32644 (WGS 84 / UTM Zone 44N)



\## Grid IDs



Each cell has a unique identifier:



HYD\_0001

HYD\_0002

...

HYD\_1543



The `grid\_id` field is the primary spatial key used to join datasets.



\## Important



This is the project's official master grid.



Team members must not independently recreate, modify, or renumber the grid.



All future datasets must retain `grid\_id`.
